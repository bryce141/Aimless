The fix in build 1.0 (4) was real but incomplete. It corrected the layout, and
the Generate button is now fully visible on iPad in every state. It did not

GUIDELINE 2.1(a) — nothing happened when tapping Generate

When Generate is tapped before the app has a location fix, build 1.0 (4) was
supposed to show an alert explaining what was needed. It could not appear, for
two reasons that compound:

1. iOS does not present an app's alert while another alert is on screen. The
   system location permission prompt is on screen during exactly the first
   seconds of first launch — which is when Generate is first tapped. Our alert
   was requested in that window and was discarded.

2. The app tracked "an explanation is owed" as a single true/false flag. Once
   set and discarded, the flag stayed set, so every later tap assigned the value
   it already held. That is not a change, so the app never asked to present
   anything again. From that point the button was silent for as long as the
   screen stayed open.

We reproduced this on an iPad Air simulator running iPadOS 26, in both states a
reviewer would be in — permission not yet answered, and permission declined. In
both, every tap produced nothing on screen. We are sorry it survived into a
second review.


WHAT CHANGED IN 1.0 (5)

We did not repair the alert. We removed the app's dependence on alerts here
entirely, and changed what a tap does.

- A tap made before the app has a location fix is no longer refused. The app
  remembers it, shows "Finding you..." with a progress indicator on the button,
  and generates automatically the moment the fix arrives. In the case you hit —
  tapping immediately on first launch — the result is now three routes rather
  than nothing. This matters most on iPad: Wi-Fi-only models have no GPS
  receiver, so the wait for a usable position is routinely several seconds.

- If a fix cannot be obtained within 15 seconds, or location access is off, the
  app explains that in a message drawn directly on screen above the button, with
  a Try Again or Open Settings control. Ordinary on-screen content draws
  correctly underneath a system prompt, where an alert cannot.

- Every tap now produces an immediate visible change and haptic feedback. There
  is no longer any state in which tapping Generate does nothing.

We also improved a second failure that could look the same to a tester. Our
routing provider cut our daily request allowance tenfold last week; when it is
exhausted, generation fails, and the app previously reported that in small text
that was easy to miss. Such failures now appear in the same prominent message as
everything else, and we have moved routing for the region your review devices
have been in onto our own infrastructure, which has no such allowance.
